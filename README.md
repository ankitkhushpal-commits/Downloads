# File download site

1. Create a GitHub repository and upload everything in this folder (index.html, style.css, script.js, files/).
2. Repo Settings > Pages > Deploy from a branch > main > / (root) > Save.
3. Open https://YOUR-USERNAME.github.io/REPO-NAME/
4. To add downloads, upload files into the `files/` folder of the repo. They show up on the site automatically.

Limits: 100 MB per file, 25 MB when uploading in the browser (use git for bigger files).
The repo must be public. Edit CONFIG in script.js if you use a custom domain.
